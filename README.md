# หลับตาครั้งนั้น คนึงฝันถึงขงจื้อ

那一次闔眼，魂牽夢縈的是孔子

เกมนิยายภาพ (เดโม 0.1) ฝันถึงขงจื้อ เรียนคำสอนจากคัมภีร์หลุนอวี่ แล้วตื่นมาเลือกคำสอนไปแก้ปัญหาในชีวิตประจำวัน 3 เรื่อง ใช้เวลาเล่นราว 15 นาที

**เล่นได้ที่:** https://jitwang12-maker.github.io/PD/

สแกนเพื่อเล่นบนมือถือ: `qr-code.png` (QR อย่างเดียว) หรือ `qr-card.png` (การ์ดพร้อมชื่อเกม สำหรับโพสต์หรือพิมพ์)

## ไฟล์

- `index.html` ตัวเกมทั้งหมด (HTML, CSS, JavaScript ในไฟล์เดียว)
- `confucius.webp` ภาพตัวละคร
- `.nojekyll` ให้ GitHub Pages ส่งไฟล์ตามที่เป็น ไม่ต้องผ่าน Jekyll

ไม่ต้อง build อะไร เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ การเซฟเกมเก็บใน `localStorage` ของเบราว์เซอร์ผู้เล่นแต่ละคน

## แก้บทเกม

บทพูดทั้งหมดอยู่ระหว่าง `/*SCRIPT-START*/` กับ `/*SCRIPT-END*/` ใน `index.html`
- `CARDS` การ์ดคำสอน
- `CASES` ชื่อปัญหาแต่ละเรื่อง
- `SCRIPT` บทของแต่ละฉาก
